# quickshell bar + notification center

Personal Hyprland desktop shell built with [Quickshell](https://quickshell.outfoxxed.me/) — a glassmorphic floating bar and a full notification center, themed live by Matugen.

Replaces: **waybar** (bar), **swaync** (notifications), originally migrated from Omarchy's defaults.

## Layout

```
shell.qml                    entry point (loads Bar)
components/
  Bar.qml                    the bar — left/center/right rows, wires everything
  Colors.qml                 Matugen palette loader (FileView + hot reload on theme change)
modules/
  ArchLogo.qml               distro logo pill
  Workspaces.qml             live Hyprland workspaces (5 persistent + dynamic)
  Clock.qml                  clock, click = alt format
  Memory.qml                 RAM usage (/proc/meminfo)
  Cpu.qml                    CPU usage (/proc/stat deltas)
  Network.qml                wifi/eth status via Quickshell.Networking
  Battery.qml                UPower battery (percentage is 0-1, ×100!)
  Temp.qml                   CPU temp, reuses scripts/temperature.sh
  ScriptIndicator.qml        generic JSON script runner (idle/update indicators)
  Tray.qml                   SNI system tray
  BellButton.qml             opens/closes the notification drawer, count badge
  DndIndicator.qml           DND toggle (moon glyph when active)
  NotificationToast.qml      glass toast popups (critical never expires, actions supported)
  NotificationCenter.qml     daemon + drawer panel + history archive
scripts/                     helper scripts the bar shells out to
```

## Notification center

- Daemon owns `org.freedesktop.Notifications` (swaync must stay gone/masked or it'll steal the bus back)
- History is self-owned archive (100 entries, newest first) — survives toast dismissal
- Drawer: `Super+Alt+,` or the bell button; `Esc` closes; per-row dismiss + clear-all + DND toggle
- IPC:
  ```
  quickshell -p ~/.config/quickshell ipc call notifications toggle
  quickshell -p ~/.config/quickshell ipc call notifications toggleDnd
  ```

## Run / develop

```bash
quickshell -p ~/.config/quickshell          # run
pkill -x quickshell                         # hard restart (auto-reload races writes)
```

Logs go wherever you redirect them; check for `ERROR`/`WARN` lines after changes.

## Theming

`Colors.qml` parses `colors.css` generated by Matugen (`~/.config/matugen/config.toml`
writes to `~/.config/quickshell/colors.css`). Theme switches propagate instantly — no restart.

Conventions baked in: every panel closes on `Esc`; icons are literal Nerd Font glyphs
(never `\uXXXX` escapes in QML); no fake data — real system APIs only.
